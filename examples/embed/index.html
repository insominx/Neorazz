Neorazz embed example

A page that frames a Neorazz host and drives it with neorazz-embed.js. Serve this folder over http (not as a file) and open it with ?host= set to your host, for example ?host=http://localhost:3000. A page on localhost is always allowed; any other site must be listed in the host's NEORAZZ_EMBED_ORIGINS. The guide is docs/embedding.md.
